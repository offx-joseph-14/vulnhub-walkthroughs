# SickOS: 1 – VulnHub Walkthrough

## Machine Information
- Difficulty: Easy
- OS: Linux

## Attack Summary
A misconfigured web server allowed directory listing and command execution.
This led to shell access and privilege escalation.

## Tools Used
- Nmap
- Gobuster
- Netcat
- Linux Enumeration

## Vulnerabilities & CVSS

1. Web Server Misconfiguration  
CVSS: 7.5 (High)

2. Remote Command Execution  
CVSS: 9.8 (Critical)

3. Privilege Escalation  
CVSS: 6.8 (Medium)

## Lessons Learned
- Secure web server configuration
- Restrict execution permissions

⚠️ Disclaimer  
This walkthrough is for educational purposes only.  
The machine was tested in a controlled lab environment provided by VulnHub.  
No real-world systems were targeted.
